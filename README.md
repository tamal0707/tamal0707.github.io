# Tamal Maitra — Animated Portfolio

## Files
- `index.html` — portfolio content
- `style.css` — responsive design + animations
- `script.js` — scroll reveals + cursor glow
- `assets/profile.png` — supplied portrait

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Add your real GitHub and LinkedIn links if you want social buttons.
3. Optionally replace/add project links.

## Publish with GitHub Pages
Create a GitHub repository, upload these files, then enable GitHub Pages from Settings → Pages.
GitHub Pages publishes static HTML/CSS/JS directly from a repository.
